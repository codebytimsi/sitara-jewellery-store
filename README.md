# SITARA — Jewellery E-Commerce Website

A responsive jewellery e-commerce website built from scratch using HTML, CSS, and JavaScript.

**Live Demo:** https://codebytimsi.github.io/sitara-jewellery-store/  
**GitHub Repository:** https://github.com/codebytimsi/sitara-jewellery-store

## ✦ About the Project

SITARA is a frontend e-commerce project inspired by modern Indian luxury jewellery brands.

The website focuses on a clean, elegant shopping experience with dynamic products, search, filtering, sorting, product details, and cart functionality.

The goal of this project was to build a complete frontend experience rather than a static landing page.

## ✦ Features

- Responsive jewellery e-commerce interface
- Dynamic product rendering using JavaScript
- Product category filtering
- Product sorting by price and name
- Product search
- Individual dynamic product pages
- Quantity controls
- Add to Cart functionality
- Remove and update cart items
- Cart persistence using LocalStorage
- Dynamic subtotal and total calculation
- Responsive design for desktop and mobile
- Checkout interaction
- Deployed using GitHub Pages
